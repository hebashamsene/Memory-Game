# 🧠 Memory Game

A simple **Memory Game** built using HTML, CSS, and JavaScript.

## ✨ Features

* Ask the player to enter their name before starting the game.
* Display the player's name, or `Unknown` if no name is entered.
* Remove the start controls after entering the name.
* Randomly shuffle the cards when the game starts.
* Flip cards when they are clicked.
* Check whether two flipped cards match.
* Keep matching cards visible.
* Count the number of wrong attempts.
* Hide unmatched cards after 1 second.
* Prevent clicking other cards while checking a pair.
* Play a success sound when two cards match.
* Play a fail sound when two cards do not match.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🚀 How to Play

1. Click the start button.
2. Enter your name.
3. Click on two cards to flip them.
4. If the two cards match, they remain visible.
5. If they do not match, the wrong attempts counter increases.
6. The unmatched cards are hidden again after 1 second.
7. Try to find the matching cards.
